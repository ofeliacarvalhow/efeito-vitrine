# Eventos

O catálogo de skins, clipes musicais, trailers e exposições, mais as
mudanças de balanceamento que entram no grupo de controle.

`montar_eventos.py` cruza as skins novas do Data Dragon com os vídeos dos
canais oficiais e escreve `data/processed/events.csv`. Os eventos que o
casamento por texto não pega entram a mão em `eventos_manuais.csv`.
