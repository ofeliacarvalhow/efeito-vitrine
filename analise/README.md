# Análise

Estatística, comparação de antes e depois, teste de placebo e os gráficos.

`efeito_vitrine.py` roda a medida inteira e escreve `relatorio.txt` e
`efeito_vitrine.html`. A tabela de resultado por campeão e por evento mora
em `coleta/resultados.py`, para o CSV da entrega e os JSON do painel saírem
da mesma conta.

Os números da análise estão descritos no README da raiz.
